# 公司数据资产申请流程

> 流程编号：PRC-2024-010 ｜ 归口部门：数据治理委员会 ｜ 版本：v3.1 ｜ 生效：2024-08-15

## 一、流程目的

规范员工申请数据资产（表、API、指标、看板）访问权限的操作，确保数据使用可追溯、可审计，符合《数据安全管理规范》。

## 二、适用范围

适用于全体正式员工、外包人员、实习生对生产环境数据资产的访问申请。测试环境数据资产无需走本流程，由各项目组自管。

## 三、流程步骤

1. **提交申请**：申请人在数据资产平台填写《数据资产访问申请单》，选择资产类型、用途说明、使用期限。
2. **直属上级审批**：直属上级在 2 个工作日内审批，核实业务必要性。
3. **数据Owner审批**：资产所属域的 Data Owner 在 3 个工作日内审批，核定权限粒度（行级/列级/脱敏）。
4. **安全合规复核**：涉及敏感字段（手机号、身份证、地址）时，安全合规岗额外复核，必要时要求脱敏视图。
5. **权限开通**：审批全通过后，权限管理平台自动开通，T+1 生效，有效期默认 90 天。
6. **到期续期**：到期前 7 天系统提醒，申请人可申请续期；未续期自动回收。

## 四、角色与职责

| 角色 | 职责 |
|---|---|
| 申请人 | 真实填写用途，按最小够用原则申请 |
| 直属上级 | 把控业务必要性，一票否决 |
| Data Owner | 核定权限粒度，负责资产准确性 |
| 安全合规岗 | 敏感字段复核，脱敏要求 |
| 权限平台 | 自动开通/回收/留痕 |

## 五、违规处理

未走流程直接使用、超范围使用、转借账号，按《数据安全管理规范》情节处理：警告 / 通报 / 降级 / 解除合同。造成数据泄露的追究法律责任。
